# OpenAILearning — UI 规格文档

日期：2026-03-27
状态：原型完成（静态 HTML），可迁移至前端框架

---

## 1. 产品概述

OpenAILearning 是一个 AI 驱动的自适应学习助手。学生输入学习主题，系统生成知识图谱，通过测验诊断掌握程度，并针对薄弱知识点生成个性化教案。

**核心循环：**
```
输入主题 → 知识图谱 → 诊断测验 → 诊断结果 → 个性化教案
```

---

## 2. 页面架构

应用由 4 个页面组成，按线性流程连接，共享 2 个公共组件。

### 2.1 页面总览

| 页面 | 文件 | 功能 | 布局 |
|------|------|------|------|
| 聊天页 | `index.html` | 主题输入、图谱展示、对话历史 | 侧栏 + 聊天区 |
| 诊断页 | `diagnosis.html` | 知识点测验（选择题） | 全屏分栏 |
| 结果页 | `results.html` | 得分汇总、知识点明细、三色图谱 | 侧栏 + 聊天区 |
| 教案页 | `lesson.html` | 个性化教学内容 + 批注 | 三栏布局 |

### 2.2 导航流程

```
聊天页 ──(开始诊断)──► 诊断页 ──(查看结果)──► 结果页 ──(开始学习)──► 教案页 ──(完成学习)──► 聊天页
                            │                                                │
                            └──(退出)──► 聊天页                               └──(返回聊天)──► 结果页
```

### 2.3 共享组件

| 组件 | 文件 | 使用页面 | 说明 |
|------|------|----------|------|
| 会话侧栏 | `sidebar.js` | 聊天页、结果页 | 对话历史列表，支持新建/删除 |
| 会话数据 | `session-data.js` | 所有页面 | 每个会话的题目、结果、教案内容 |

## 3. 各页面详细规格

### 3.1 聊天页（`index.html`）

**布局：** 左侧栏（可收缩，256px）+ 中央聊天区 + 底部输入栏

#### 3.1.1 会话侧栏
- **位置：** 固定左侧，全高，位于顶部导航栏下方
- **宽度：** 256px，通过边缘箭头按钮收缩/展开
- **收缩行为：** 侧栏通过 `margin-left` 动画向左滑出（300ms）。聊天区和底部输入栏自动扩展填满。箭头图标翻转方向（`<` ↔ `>`）
- **组成部分：**
  - "New Session" 按钮（顶部，主色调蓝色）
  - 会话列表（可滚动，最新在最上面）
  - 每条会话显示：聊天图标 + 会话名称（超长截断）
  - 当前会话：实心图标，蓝色高亮背景
  - 鼠标悬停：右侧出现三个浅灰色圆点按钮
  - 点击圆点按钮：弹出下拉菜单，包含"Delete"选项
  - 删除：弹出确认对话框（"Are you sure you want to delete...?"），确认后从 localStorage 移除该会话

#### 3.1.2 聊天区
- **样式：** ChatGPT 风格对话流，最大宽度 896px，居中
- **用户消息：** 右对齐，圆角气泡（右上角为直角）
- **AI 回复：** 左对齐，带头像图标，包含：
  - 标题（Headline 字体，主色调）
  - 描述文字
  - 内嵌知识图谱（见 3.1.3）
  - "Start Diagnosis" 按钮（绿色，图谱卡片内全宽）

#### 3.1.3 内嵌知识图谱
- **容器：** 白色卡片，大圆角（2.5rem），最小高度 400px
- **可视化：** 网络图，中心为主题节点，周围 4 个关联知识点节点
- **连线：** SVG 线段从中心连接到各节点（低透明度）
- **节点样式：** 大写文字标签，slate-400 颜色，悬停时平移 + 变色
- **节点不可编辑**

#### 3.1.4 底部输入栏
- **位置：** 固定底部，宽度跟随侧栏变化
- **组成：** 文本输入框（圆角，右侧发送按钮）+ 下方建议快捷按钮
- **快捷按钮：** 与当前主题相关的上下文操作建议

#### 3.1.5 动态内容
- 内容根据当前选中的会话动态切换（数据存储在 localStorage）
- 每个会话有独立的：用户消息、AI 标题/描述、图谱节点、建议按钮
- 数据来源：`session-data.js` → 生产环境替换为 API 调用

### 3.2 诊断页（`diagnosis.html`）

**布局：** 全屏，无侧栏。顶部导航含进度条 + 分栏内容区

#### 3.2.1 顶部导航
- 左侧：应用 Logo + "Diagnosis Mode" 标签
- 右侧："Exit" 链接 → 返回聊天页
- 导航栏下方：进度条，显示 "Question X / N" + 线性进度指示器

#### 3.2.2 分栏内容区
- **左侧（flex-1）：题目面板**
  - 知识点标签（胶囊徽章，带标签图标，浅蓝背景）
  - 题目文字（Headline 字体，xl 字号）
  - "Select one answer" 提示文字
- **右侧（420px）：作答面板**
  - 4 个选项按钮（A/B/C/D），每个包含：
    - 字母徽章（圆角方块，灰色背景）
    - 选项文字
    - 选中状态：蓝色背景，白色文字，字母徽章反转配色
  - "Next Question" 按钮（未选择时禁用，主色调）
  - 最后一题：按钮文字变为 "Finish"

#### 3.2.3 完成状态
- 替换主内容区为居中完成消息
- 绿色对勾图标 + "Diagnosis Complete" 标题
- "View Results" 按钮 → 跳转到结果页

#### 3.2.4 交互流程
1. 学生阅读题目，点击一个选项（高亮选中 + 启用下一题按钮）
2. 点击"Next Question"手动推进到下一题
3. 进度条更新：宽度百分比 + "Question X/N" 文字
4. 最后一题答完 → 显示完成界面
5. 点击"View Results" → 跳转结果页

### 3.3 结果页（`results.html`）

**布局：** 与聊天页一致（侧栏 + 聊天区 + 底部输入栏）

#### 3.3.1 对话历史
展示对话上下文：
1. 原始用户消息（"我想学习..."）
2. 折叠的 AI 回复（"已梳理知识图谱并开始诊断"）
3. 完整诊断结果回复（见下文）

#### 3.3.2 得分汇总卡片
- **左侧：** 环形进度圈（SVG，根据正确率计算 dash-offset）
  - 中央显示大号百分比数字
  - 下方 "Accuracy" 标签
- **右侧：** 统计列表
  - 总题数 / 正确数（绿色）/ 错误数（红色）

#### 3.3.3 知识点明细
- 知识点列表，每项包含：
  - 状态图标：绿色勾（已掌握）/ 红色叉（薄弱）/ 灰色圆圈（跳过）
  - 知识点名称
  - 状态标签："2/2 已掌握"（绿色）/ "1/3 需复习"（红色）/ "已跳过"（灰色）

#### 3.3.4 薄弱知识点提示
- 警告卡片（浅红背景，红色边框）
- 警告图标 + 标题"薄弱知识点"
- 描述文字列出具体薄弱领域 + "已为你准备了针对性的教案"

#### 3.3.5 三色知识图谱
- 与聊天页相同的网络图布局
- 节点按状态着色：
  - 绿色圆点 + 绿色文字 = 已掌握
  - 红色圆点 + 红色文字 = 未掌握
  - 灰色圆点 + 灰色文字 = 跳过（推断掌握）

#### 3.3.6 操作按钮
- "Start Learning" 按钮（主色调蓝色，带学校图标）
- 点击跳转到教案页

### 3.4 教案页（`lesson.html`）

**布局：** 三栏 — 左侧大纲目录（可收缩）+ 中央教案内容（含右侧批注栏）+ 右侧知识图谱

#### 3.4.1 顶部导航
- 左侧：应用 Logo + "Lesson Mode" 标签
- 右侧："Back to Chat" 链接 → 返回结果页

#### 3.4.2 大纲目录侧栏（左侧，240px）
- **标题：** "OUTLINE" 标签
- **内容：** 根据教案章节自动生成的分层列表
  - 第一层（h2）：知识点名称，带红色圆点标识，加粗
  - 第二层（h3）：子标题，缩进显示，字号更小
- **滚动追踪：** 根据内容区滚动位置自动高亮当前所在的大纲条目
- **点击导航：** 点击任意条目，内容区平滑滚动到对应章节
- **收缩功能：** 边缘箭头按钮（与聊天页侧栏一致），通过 margin 动画向左滑出

#### 3.4.3 教案内容区（中央）
- **宽度：** 最大 680px，右侧预留 230px 批注栏空间
- **页头：** "个性化教案" 标签 + 教案标题 + 描述文字（薄弱知识点标红）
- **章节：** 每个薄弱知识点对应一个章节，包含：
  - 章节标题（带红色圆点）
  - 正文讲解
  - 概念卡片（浅蓝背景，圆角）
  - 例题卡片（灰色背景，左侧蓝色竖线）
  - 要点列表（无序列表）
- **完成按钮：** 页面底部 "Finish Learning" → 返回聊天页

#### 3.4.4 文字批注系统
- **选中文字：** 鼠标左键拖选教案正文中的任意文字
- **弹出工具栏：** 选中文字下方出现 "Note" 按钮（浮动，淡入动画）
- **输入笔记：** 点击 Note → 弹出输入框，输入笔记内容，按 Enter 保存
- **展示效果：**
  - 选中的文字变为蓝色高亮（背景 `#d4e3ff`，蓝色下划线）
  - 笔记卡片出现在右侧批注栏，垂直位置与高亮文字对齐
  - 卡片内容："NOTE" 标题 + 引用原文（截断显示）+ 笔记正文
  - 卡片左侧有连接线指向正文区域
- **删除笔记：** 点击笔记卡片右上角 × → 同时移除正文高亮和卡片
- **取消输入：** 输入过程中按 Esc 取消

#### 3.4.5 知识图谱侧栏（右侧，340px）
- **标题：** "KNOWLEDGE MAP" + "薄弱知识点高亮"
- **图谱：** 迷你网络图，仅显示薄弱（红色）知识点节点
  - 节点可点击 → 平滑滚动到对应教案章节
  - 红色圆点，悬停时有光环脉冲效果
  - 中心显示主题名称（弱化显示）
- **学习进度：** 底部区域包含：
  - 章节名称标签
  - "第 X/N 节" 计数器（随滚动更新）
  - 进度条（根据滚动位置填充）

## 4. 设计系统

### 4.1 字体

| 角色 | 字体 | 用途 |
|------|------|------|
| 标题字体 | Manrope（600-800） | 标题、按钮、标签 |
| 正文字体 | Inter（400-600） | 内容文字、描述 |
| 标注字体 | Inter（500-600） | 标签、徽章、小号 UI 文字 |

### 4.2 配色方案

| 色彩令牌 | 色值 | 用途 |
|----------|------|------|
| primary | `#005da7` | 链接、激活态、主按钮 |
| primary-container | `#2976c7` | 按钮悬停态 |
| primary-fixed | `#d4e3ff` | 浅蓝背景、文字高亮 |
| secondary | `#3c692b` | 成功状态、"开始"按钮、已掌握节点 |
| error | `#ba1a1a` | 错误状态、薄弱节点、警告 |
| on-surface | `#191c1e` | 主要文字 |
| on-surface-variant | `#414751` | 次要文字 |
| surface | `#f7f9fb` | 页面背景 |
| outline | `#717783` | 边框、非激活图标 |

### 4.3 组件样式规范

| 组件 | 样式 |
|------|------|
| 卡片 | 白色背景，`border-slate-100`，圆角 3xl，shadow-sm |
| 主按钮 | 主色调背景，白色文字，圆角 2xl，悬停 shadow-sm → shadow-md |
| 次按钮 | 绿色背景，白色文字，全圆角 |
| 标签/徽章 | 全圆角，小号字体，有色背景配同色文字 |
| 输入框 | 白色背景，灰色边框，圆角 2xl，聚焦时主色调光环 |
| 进度条 | slate-100 轨道，主色调填充，全圆角，1.5px 高度 |
| 弹窗对话框 | 白色背景，圆角 3xl，黑色半透明遮罩 |

### 4.4 动画过渡

| 元素 | 属性 | 时长 | 缓动 |
|------|------|------|------|
| 侧栏收缩 | margin-left | 300ms | ease |
| 按钮悬停 | shadow, background | 150ms | ease-in-out |
| 选项选中 | border, background, color | 150ms | ease-in-out |
| 工具栏/弹出框 | opacity, transform | 120ms | ease-out |
| 进度条 | width | 300ms | default |

### 4.5 图标

- **图标库：** Google Material Symbols Outlined
- **使用的图标：** `add`、`chat_bubble`、`smart_toy`、`arrow_upward`、`close`、`label`、`arrow_forward`、`check_circle`、`cancel`、`warning`、`school`、`more_horiz`、`delete`、`edit_note`、`sticky_note_2`、`chevron_left`、`chevron_right`、`arrow_back`、`menu`

## 5. 响应式设计

当前原型仅适配桌面端（最小宽度约 1200px）。后续考虑：
- 平板：默认收起侧栏，诊断页改为上下堆叠布局
- 手机：单栏布局，图谱和选项使用底部抽屉

---

## 6. 数据流（原型 → 生产环境）

| 原型（当前） | 生产环境（目标） |
|-------------|-----------------|
| `session-data.js` 硬编码对象 | `POST /graph/generate` API |
| `questions[]` 数组 | `POST /diagnosis/generate` API |
| 静态得分/明细 | `POST /diagnosis/result` API |
| 硬编码教案 HTML | `POST /lesson/generate` API |
| `localStorage` 会话 | 数据库 + 用户认证 |
| 多页面 HTML 跳转 | SPA 路由（平滑过渡） |
| 静态 SVG 图谱 | D3.js / vis.js 动态网络图 |
| 内存中的笔记 | `POST /notes/save` API |
