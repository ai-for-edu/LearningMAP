# AI Education Assistant — Design Document

Date: 2026-03-27

## 1. Overview

AI 教育助手，通过知识图谱驱动的自适应诊断和个性化教案生成，帮助学生高效学习任意主题。

**两大模块：**
- **交互模块**（本文档聚焦）：知识图谱生成 → 诊断出题 → 教案学习
- **记忆模块**：全流程记录 + 历史检索复用（后续设计）

**目标用户：** 通用，不限学段和学科。

**UI 生成方式：** 使用 Google Stitch 通过 prompt 生成前端页面。

---

## 2. 核心流程

```
学生输入主题
    ↓
LLM 生成知识图谱（网络图，节点数可配上限）
    ↓
聊天流中展示知识图谱（不可编辑）
    ↓
平滑过渡 → 诊断态（左题目 + 右作答）
    ↓
每个知识点 2-3 道选择题
答对高阶节点 → 前置节点自动标记灰色跳过
    ↓
诊断结束 → 展示结果图谱
  绿色 = 掌握 | 红色 = 未掌握 | 灰色 = 跳过（被推断掌握）
    ↓
平滑过渡 → 学习态（左教案 + 右裁剪图谱）
  教案只覆盖红色节点
    ↓
学习结束 → 平滑收起，回到聊天态（不留记录）
    ↓
全流程写入 memory，供下次检索
```

---

## 3. UI 三态设计

### 3.1 聊天态

- ChatGPT 风格对话界面
- 学生输入"我要学习 xxx"后，LLM 回复中内嵌知识图谱（网络图）
- 图谱节点可点击，弹出知识点说明 + 关联题目/学习状态
- 图谱下方有"开始诊断"按钮，点击后聊天区收起，平滑展开为分区式

### 3.2 诊断态（分区式）

- **左侧：题目区**
  - 一次显示一道选择题
  - 顶部进度条："第 3/12 题"
  - 题目包含所属知识点标签
  - 学生选择后点"下一题"手动推进
- **右侧：作答区**
  - 选项列表（A/B/C/D），点击选择
  - "下一题"按钮

### 3.3 诊断结果展示

- 全屏展示知识图谱
- 节点三色标记：绿（掌握）/ 红（未掌握）/ 灰（跳过）
- 点击节点可查看该知识点的题目和学生作答情况
- "开始学习"按钮，进入学习态

### 3.4 学习态（分区式）

- **左侧：教案区** — 纯文本讲解，只覆盖未掌握（红色）知识点
- **右侧：裁剪后知识图谱** — 只显示红色节点及其关联，学习中的节点高亮
- 学习完成后平滑收起，回到聊天态

## 4. 后端交互逻辑

### 4.1 API 设计

| API | 输入 | 输出 | 说明 |
|-----|------|------|------|
| `POST /graph/generate` | 主题名称, max_nodes | 知识图谱 JSON（节点+边+描述） | LLM 实时生成 |
| `POST /diagnosis/generate` | 知识图谱, 已跳过节点 | 题目列表（每节点2-3题选择题） | LLM 出题 |
| `POST /diagnosis/submit` | 题目ID, 学生答案 | 对错结果, 是否触发前置跳过 | 逐题提交判定 |
| `POST /diagnosis/result` | session_id | 图谱 + 三色标记 | 汇总诊断结果 |
| `POST /lesson/generate` | 裁剪后图谱（红色节点） | 教案文本 | LLM 生成教案 |
| `POST /memory/save` | session_id, 全流程数据 | 确认 | 存入记忆模块 |
| `POST /memory/retrieve` | 主题/query | 历史学习记录 | 下次检索复用 |

### 4.2 知识图谱数据结构

```json
{
  "topic": "二元一次方程",
  "nodes": [
    {"id": "n1", "name": "一元一次方程", "description": "...", "level": "prerequisite"},
    {"id": "n2", "name": "二元一次方程定义", "description": "...", "level": "core"}
  ],
  "edges": [
    {"from": "n1", "to": "n2", "relation": "prerequisite"}
  ]
}
```

### 4.3 诊断跳过逻辑

```
当学生答对节点 X 的多数题目（如 2/3）:
  1. 标记 X 为绿色（掌握）
  2. 查找 X 的所有前置节点（沿 edge 反向遍历）
  3. 前置节点标记为灰色（跳过），移出待诊断队列
```

### 4.4 Memory 存储结构

```json
{
  "student_id": "...",
  "session_id": "...",
  "topic": "二元一次方程",
  "timestamp": "2026-03-27T...",
  "graph": {},
  "diagnosis_results": {
    "n1": {"status": "skipped"},
    "n2": {"status": "mastered", "questions": [], "answers": []},
    "n3": {"status": "not_mastered", "questions": [], "answers": []}
  },
  "lesson_content": "..."
}
```

## 5. MVP 边界

### 做

- LLM 实时生成知识图谱（网络图）
- 选择题诊断（每知识点 2-3 题）
- 答对高阶 → 前置自动跳过
- 三色结果图谱展示
- 纯文本教案生成
- 全流程写入 memory

### 不做（后续迭代）

- 再测环节
- 填空题/简答题等非选择题型
- 对话式教学/多媒体教案
- 预建知识图谱
- 学生编辑图谱
- 诊断态中途退出/恢复
