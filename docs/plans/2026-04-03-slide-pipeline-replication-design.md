# 全面复刻 OpenMAIC 幻灯片生成管线

## 概述

参照 OpenMAIC 的 scene-generator.ts、json-repair.ts、interactive-post-processor.ts、use-export-pptx.ts，全面升级 OpenAIL 的幻灯片生成管线，消除与 OpenMAIC 的质量差距。

## 3 个 Batch

### Batch 1: 核心质量
1. JSON 修复模块
2. 元素默认值修复完善
3. LaTeX 处理

### Batch 2: 样式完整
4. HTML 文本样式完善
5. SVG 形状完善
6. 图片管道

### Batch 3: 增强
7. 渐变背景
8. 阴影效果
9. 调试日志
